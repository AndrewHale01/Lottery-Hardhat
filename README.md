# Лотерея на Hardhat

Окремий навчальний проєкт: смартконтракт Solidity, Hardhat-тести та React-інтерфейс із MetaMask.

Квиток коштує `0.01 ETH`. Кожна адреса може приєднатися один раз за раунд і вказати нікнейм (до 32 байтів UTF-8). Застосунок показує поточних учасників і нікнейм останнього переможця. Власник контракту визначає переможця; весь приз надсилається автоматично.

> Вибір переможця використовує дані блока для псевдовипадкового числа. Цей навчальний приклад не підходить для лотерей із реальними коштами.

## Встановлення та запуск

У PowerShell відкрийте цю папку:

```powershell
cd "$HOME\Desktop\Lottery-Hardhat"
npm install
```

Запустіть локальний блокчейн Hardhat у першому терміналі:

```powershell
npm run node
```

Розгорніть контракт у другому терміналі:

```powershell
npm run deploy:local
```

Команда розгортання записує адресу контракту й ABI у `frontend/public/contract.json`.

Додайте локальну мережу в MetaMask:

- RPC URL: `http://127.0.0.1:8545`
- Chain ID: `31337`
- Назва: `Hardhat Local`

Імпортуйте один із тестових акаунтів, показаних командою `npm run node`, щоб отримати локальний тестовий ETH. Відкрийте React-застосунок у третьому терміналі:

```powershell
npm run dev
```
